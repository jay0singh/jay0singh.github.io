04. Things I've built

Agentic RAG System

A multi-tool RAG system built on LangGraph: a router classifies each question and dispatches to hybrid document search (vector + full-text, fused via reciprocal rank fusion), live web search, or the GitHub API. Every answer is graded by an LLM-as-judge loop that auto-retries ungrounded responses and escalates unresolved ones to a human-in-the-loop queue — whose answers are embedded back into the knowledge base, so it learns from its own failures. Ships with token streaming, persistent multi-turn chat, source citations, and full Langfuse observability — gated by a 113-test CI suite and running entirely on free-tier cloud.

Conversational SQL Agent — F1

Ask questions about Formula 1 in plain English and get back the generated SQL, the result table, and a natural-language answer. A LangGraph state machine injects the live schema, generates SQL (Groq / Llama 3.3 70B), and self-corrects from real database errors. Because it executes LLM-written SQL, it's defended in depth — a read-only DB role, AST-based query validation (SELECT-only via sqlglot), and an 8s statement timeout, proven by hostile-prompt safety tests. Backed by an idempotent, resumable ETL pipeline (~390K rows, weekly CI refresh) and a streaming React UI, shipped as a single Docker container on Render.

AI Code Review Agent

A deployed GitHub App that reviews pull requests with an LLM: it fetches the diff, sends it for a senior-level review, and posts line-anchored, severity-tagged inline comments (🔴 blocker · 🟡 warning · 🔵 nit) — staying quiet when there's nothing worth flagging. Its standout is a human-in-the-loop approval gate: every review is routed to a Telegram bot with Approve / Reject buttons and posts to GitHub only after a maintainer approves. Async FastAPI service with HMAC-verified webhooks, self-rotating GitHub App tokens, webhook dedupe, and ~140 tests, running live on Render. (Demo link → an example PR the agent reviewed.)

URL Shortener Service

A production full-stack shortener — Spring Boot REST API + an Angular SPA. Generates short codes via Base62 encoding of the database id, redirects with hit-count / last-accessed tracking, and supports TTL expiry with a scheduled cleanup job. Deduplicates URLs (resubmitting returns the existing code; expired links reactivate), with per-IP rate limiting (Bucket4j), a Caffeine redirect cache, Basic-Auth-protected admin endpoints, and a partial index to keep cleanup fast at scale. Deployed on Railway (API + Postgres) and Vercel.
